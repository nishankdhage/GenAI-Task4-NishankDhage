1. Introduction
This project demonstrates basic file handling operations in Python.
The assignment focuses on creating files, writing data, reading data, appending records, and generating reports using Python's built-in file handling features.

2. Concepts Used
- Opening files using open()
- File modes: r, w, a, r+, w+
- Reading using read(), readline(), and readlines()
- Writing data using write()
- Appending data to existing files
- Using with open() for safe file handling
- Basic calculations using lists and dictionaries
- Checking file existence using os.path.exists()

4. Generated Files
- sales_data.txt
- products.txt
- discount_report.txt

5. Technologies Used
- Python 3
- VS Code
- Built-in Python file handling
- Basic Python lists, loops, and dictionaries

6. How to Run
Open the project folder in VS Code.

Open the terminal and execute:
python task1_write_sales.py
python task2_read_sales.py
python task3_append_sales.py
python task4_sales_report.py

7. Conclusion
This project provides practical experience with Python file handling. It demonstrates how to store, retrieve, update, and process information using text files without external libraries
